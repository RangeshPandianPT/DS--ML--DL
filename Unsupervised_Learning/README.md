# Unsupervised Learning

This folder contains resources and implementations for various Unsupervised Learning algorithms.
Unlike Supervised Learning, these models find hidden patterns or intrinsic structures in data without relying on labeled outcomes.

## Topics Covered
1. **Clustering**
   - K-Means Clustering
   - Hierarchical Clustering
   - DBSCAN

2. **Dimensionality Reduction** (Coming Soon)
   - Principal Component Analysis (PCA)
   - t-SNE
